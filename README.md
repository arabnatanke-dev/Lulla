# Lulla

Мобильное приложение со спокойными детскими сказками для Android и iOS. Проект создан на Expo SDK 54, React Native и TypeScript по техническому заданию MVP.

Создатель: **Abdulla Chukhray**

Контакт: **[arabnatanke@gmail.com](mailto:arabnatanke@gmail.com)** · [GitHub](https://github.com/arabnatanke-dev)

## Что реализовано

- онбординг из трёх экранов;
- главная страница, каталог, избранное и настройки;
- системная, светлая и тёмная темы с сохранением выбора;
- собственный нейтральный логотип Lulla с лампой и раскрытой книгой;
- поиск по названию и описанию;
- фильтрация по пяти категориям;
- 10 адаптированных сказок на русском и английском;
- 10 оптимизированных локальных обложек;
- 20 локальных аудиофайлов — по одной озвучке на каждый язык;
- полный плеер, мини-плеер, перемотка и четыре скорости;
- сохраняемая очередь с автоматическим переходом к следующей сказке;
- повтор одной сказки или всей очереди по выбору пользователя;
- таймер сна на 5, 10, 15 и 30 минут или до конца сказки;
- одновременное чтение и прослушивание;
- три размера текста;
- сохранение языка, избранного, прогресса и скорости в AsyncStorage;
- офлайн-работа основного контента;
- фоновое аудио и системные кнопки управления на экране блокировки Android и iOS.

В исходном коде перед основными функциями и обработчиками добавлены пояснения на русском языке.

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить Expo:

```bash
npm start
```

После запуска можно:

- отсканировать QR-код приложением Expo Go;
- нажать `i` для iOS Simulator;
- нажать `a` для Android Emulator;
- нажать `w` для web-версии.

## Сборка Android

Установочный APK для телефона собирается профилем `preview`:

```bash
npx eas-cli build --platform android --profile preview
```

Для публикации в Google Play используется профиль `production`, который создаёт файл AAB:

```bash
npx eas-cli build --platform android --profile production
```

## Структура

```text
app/                    экраны и маршруты Expo Router
src/components/         общие элементы интерфейса
src/context/            настройки и единый аудиоплеер
src/data/               тексты, переводы и метаданные сказок
src/services/           локальное хранилище
src/constants/          цвета, скругления и тени
src/types/              TypeScript-типы
assets/images/covers/   локальные обложки
assets/audio/ru/        русская озвучка
assets/audio/en/        английская озвучка
```

## Контент и озвучка

Тексты являются самостоятельными детскими адаптациями классических сюжетов. Они смягчены для вечернего прослушивания: жестокие и пугающие детали исключены.

В репозитории уже находятся готовые MP3-файлы. Команда ниже нужна только для их повторной генерации на macOS. Для кодирования должен быть установлен `lame` (`brew install lame`):

```bash
npm run generate:audio
```

Для публичного релиза синтезированную озвучку рекомендуется заменить профессиональной студийной записью, сохранив текущие имена файлов.

## Технические примечания

- В MVP нет регистрации, сервера, рекламы, оплаты и сбора персональных данных.
- Фоновое воспроизведение в Expo Go ограничено возможностями контейнера. Полностью оно проверяется в development/standalone-сборке Android или iOS.
- EAS хранит номер нативной сборки удалённо и автоматически увеличивает его, чтобы новые APK/AAB устанавливались как обновления.
- Перед публикацией необходимо добавить публичные ссылки на политику конфиденциальности и условия использования.
